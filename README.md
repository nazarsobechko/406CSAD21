## Опис

Лабораторна робота присвячена створенню AI-агента **Build Engineer** для
автоматизації розробки та CI/CD JavaScript-проєкту з npm scripts і Jest.
У репозиторії збережено лише агента, skills, prompts і документацію. Сам
Hello World-проєкт тут не створюється.

## Запуск агента

Відкрийте репозиторій у Visual Studio Code, відкрийте Copilot Chat, виберіть
агента **Build Engineer** і виконайте `/init`. Для окремої перевірки без
змін використовуйте `/check`. Детальні команди наведені в
[docs/usage.md](docs/usage.md), а схема взаємодії — у
[docs/architecture.md](docs/architecture.md).
